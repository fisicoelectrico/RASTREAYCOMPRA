# Mockup navegable de RastreaYCompra

Prototipo visual estático (HTML + JS sin dependencias) para revisar el diseño **antes** de construir la app.
Abre `index.html` en el navegador. Todos los precios, tiendas e historial son datos de ejemplo.

Pantallas: buscar con coincidencias agrupadas por modelo, elegir ofertas por tienda (nueva/usada/ambas),
precio objetivo y alertas, lista de vigilados, detalle con historial por tienda y alertas.
